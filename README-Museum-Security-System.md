# 🏛️ 박물관이 살아있다! (Museum is Alive!)
**웹캠과 터틀로봇을 활용한 박물관 도난 방지 스마트 보안 시스템**
*(ROS2를 활용한 로봇 자동화 공정 시스템 구현 프로젝트)*

---

## 📌 프로젝트 개요
전 세계적으로 연간 수만 건의 미술품 도난 사건이 발생하지만, 회수율은 10%에 불과합니다. 기존 박물관 보안 시스템은 CCTV 사각지대, 실시간 대응 지연, 막대한 야간 경비 인력 비용 등의 한계가 존재합니다. 
본 프로젝트는 **웹캠과 ROS2 기반의 터틀로봇(AMR)**을 활용하여 전시물을 실시간으로 모니터링하고, 도난 발생 시 즉각적으로 알림을 발생시키며 로봇이 출동해 도둑을 추적하는 **지능형 스마트 보안 시스템**을 제안합니다.

---

## ⚙️ 주요 기능 및 시스템 흐름

1. **탐지 (Detection)**
   * 전시 공간에 설치된 웹캠을 통해 실시간 모니터링 수행
   * YOLOv8 기반 객체 인식 모델을 활용하여 전시물(유물) 상태 파악
2. **판단 (Judgment)**
   * 전시물 미탐지 시 즉각적으로 도난 이벤트(위험 상태) 발생
3. **알림 (Alarm/System)**
   * 관리자 웹 대시보드에 Alert Popup 발생 및 도난 시간, 캡처 이미지, 관련 로그 전송
   * 웹 기반 모니터링 UI에서 실시간 웹캠 및 터틀봇 영상 확인 가능
4. **대응 (AMR/Tracking)**
   * 도난 이벤트 수신 시 터틀봇(AMR)이 현장으로 즉시 출동
   * OAK-D 카메라(Depth)를 활용한 3D 좌표 변환으로 도둑의 위치 추정 및 추적

---

## 🛠️ 기술 스택 및 활용 장비

* **Hardware**
  * TurtleBot (AMR) - Raspberry Pi 4B, LiDAR, OAK-D (Depth Camera)
  * Web Camera (RGB 영상 입력)
  * PC (Ubuntu 22.04)
* **Software & Frameworks**
  * ROS2 (Humble)
  * Python, OpenCV
  * YOLOv8 (객체 탐지)
  * 웹/DB 환경 구성 (Flask 기반 서버 통신)

---

## 📈 프로젝트 성과 및 리뷰
* **정확도:** YOLOv8 모델 학습 결과 mAP50 0.9944 달성
* **통합 시스템 구현:** 단순한 객체 인식을 넘어 웹캠, 서버, DB, 로봇(AMR)을 하나로 연동하는 성공적인 파이프라인 구축
* **자체 평가:** 도난 감지부터 팝업 알림, 로그 저장, AMR 로봇의 물리적 추적까지 전체 시나리오를 완벽하게 구현하였습니다. 향후 실제 로봇 환경에서의 네트워크 지연 및 센서 오차를 보완한다면 더욱 완성도 높은 시스템이 될 것입니다.
